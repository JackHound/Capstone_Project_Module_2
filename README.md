## Overview
Proyek analisis data tagihan IPL (Iuran Pengelolaan Lingkungan) untuk memahami pola Non-Paying Invoices (NPI), tunggakan, aktivitas penagihan, dan sengketa pembayaran.


## Objectives
- Mengukur tingkat NPI dan nilai tagihan yang belum dibayar.
- Menganalisis NPI berdasarkan usia tunggakan, lokasi, status unit, dan karakteristik penagihan.
- Mengevaluasi aktivitas collection serta pola sengketa pembayaran.
- Menyajikan temuan melalui visualisasi dan dashboard di Tableau Public.


## Tools
- Python / Pandas — pengolahan dan analisis data.
- Tableau Public — visualisasi dan dashboard interaktif.
- CSV — data hasil olahan untuk setiap chart.


## Dashboards
1. Executive NPI — baseline NPI, rekonsiliasi, aging tunggakan, work route, township, dan cluster.
2. Diagnostic — NPI berdasarkan vacancy, kontak, autodebit, billing channel, tren bulanan, dan indikator data air.
3. Collection & Disputes — alasan sengketa, umur backlog, cakupan collection, respons penagihan, dan analisis sensitivitas.


## Key Definitions
- NPI: invoice dengan status pembayaran Unpaid atau Overdue.
- B0: baseline awal sebelum penyesuaian pembatalan.
- B1: baseline setelah mengecualikan pembatalan yang telah dikonfirmasi.
- Penyesuaian B0 ke B1 adalah penyesuaian administratif, bukan bukti pemulihan kas.


## Baseline Summary
- B0: 807.427 invoice; 298.426 NPI; tingkat NPI sekitar 36,96%; outstanding sekitar Rp246,40 miliar.
- B1: 790.817 invoice; 289.981 NPI; tingkat NPI sekitar 36,67%; outstanding sekitar Rp230,33 miliar.
